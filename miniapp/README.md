# miniapp: фронтенд мини-аппа (MAX)

Веб-страница со списком задач и встреч.

## Что умеет
- Вкладки периода: сегодня / завтра / неделя
- Фильтр по типу: задачи / встречи / напоминания
- Поиск по смыслу (`GET /v1/events/search`)
- Кнопка «В календарь» (`GET /v1/events/{id}/ics`)
- Пустое состояние и состояние ошибки с кнопкой «Повторить»

## Как запустить локально
1. Открыть `miniapp/index.html` через расширение Live Server в VS Code.
2. Добавить в адрес параметры: `?user_id=test_maria`
3. Адрес бэкенда по умолчанию `http://localhost:8000`.
   Переопределить можно так: `?user_id=test_maria&api=https://АДРЕС`

## user_id
- Для разработки: параметр `?user_id=...` в адресе.
- Внутри MAX: берётся из MAX Bridge (`window.WebApp.initDataUnsafe.user.id`).
  Это данные без проверки подписи. Для рабочего режима бэкенд должен проверять
  подписанный `initData` (`window.WebApp.initData`).
